## 🇺🇸 English

**What it does.** A reverse-lookup glossary: turns a vague description ("the bouncy thing when a popover opens") into the exact term (*Pop in*), so you can ask for animations precisely.

**Core takeaways.**
- Describe the effect → get the name, definition and how it's usually built.
- Precise words produce better animations from any agent.

**When to use.** "What's it called when…?", writing briefs for motion.

**When NOT to use.** Building the animation itself.

## 🇧🇷 Português

**O que faz.** Glossário reverso: transforma uma descrição vaga ("aquela coisa que quica quando o popover abre") no nome exato do efeito.

**Principais lições.**
- Descrever o efeito → receber o nome e como se faz.
- Palavras certas geram animações melhores.

**Quando usar.** "Como se chama quando…?"; pedir animações com precisão.

**Quando NÃO usar.** Construir a animação.
