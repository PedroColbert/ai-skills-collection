## 🇺🇸 English

**What it does.** Guide to **Sonner**, Emil's React toast library: setup, picking the right `toast()` call, promise/loading toasts, updating and dismissing, styling escalation, positioning, troubleshooting.

**Core takeaways.**
- Mount one `<Toaster />`; pick the call by intent (success, error, promise, custom).
- Styling escalation ladder: options → classNames → unstyled → custom.
- Troubleshooting table for toasts that don't appear or look wrong.

**When to use.** Any React project with toasts.

**When NOT to use.** Non-React stacks.

## 🇧🇷 Português

**O que faz.** Guia do **Sonner**, a biblioteca de notificações (toasts) para React do Emil.

**Principais lições.**
- Um único `<Toaster />`.
- Escolher a chamada pela intenção.
- Escada de estilização e tabela de problemas comuns.

**Quando usar.** Projetos React com notificações.

**Quando NÃO usar.** Sem React.
