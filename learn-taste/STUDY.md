## 🇺🇸 English

**What it does.** Run at the end of a session: collects every design correction (including edits you made yourself) and turns each into a rule *with its reason* in `DESIGN.md`, a project skill, or a lint check.

**Manual only:** `disable-model-invocation: true` — Claude never picks it on its own; you start it by typing `/learn-taste`.

**Core takeaways.**
- Only the user's taste — never a rule because it "seems like good practice".
- Never invent a why; inferred reasons are marked and confirmed.
- Propose, then stop: writes only approved items.
- A check beats a sentence (lint rule, token restriction, test).
- Make sure `CLAUDE.md`/`AGENTS.md` points to `DESIGN.md`.

**When to use.** End of design sessions (e.g. portfolio work, where many decisions are already in `CLAUDE.md`).

**When NOT to use.** Sessions with no design corrections.

## 🇧🇷 Português

**O que faz.** Rodar no fim da sessão: junta todas as correções de design que você fez e transforma cada uma numa regra com o motivo, no `DESIGN.md`, numa skill do projeto ou numa verificação automática.

**Só manual:** `disable-model-invocation: true` — o Claude não usa sozinho; você inicia digitando `/learn-taste`.

**Principais lições.**
- Só o gosto do usuário.
- Nunca inventar o motivo.
- Propõe e espera aprovação.
- Uma verificação automática vale mais que uma frase.

**Quando usar.** Fim de sessões de design.

**Quando NÃO usar.** Sessões sem correções de design.
