## 🇺🇸 English

**What it does.** Official GSAP skill for plugins: registration, ScrollTo, ScrollSmoother, Flip, Draggable, Inertia, Observer, SplitText, ScrambleText, DrawSVG, MorphSVG, MotionPath, CustomEase and friends.

**How it works.** One `SKILL.md` organised by plugin family (scroll, DOM/UI, text, SVG, easing) with links to the docs.

**Core takeaways.**
- **All GSAP plugins are free** since Webflow's acquisition, including SplitText and MorphSVG.
- Install from the public `gsap` package; never generate an `.npmrc` with a GreenSock token (outdated).
- Register every plugin before use.
- Pick the plugin for the job: Flip for layout changes, Observer for gesture input, SplitText for text reveals.

**When to use.** Any GSAP plugin work (the portfolio uses SplitText and ScrambleText).

**When NOT to use.** Non-GSAP stacks.
