## 🇺🇸 English

**What it does.** How to write modern Swift well: value types, errors and optionals, Swift 6 data-race safety and approachable concurrency (`@concurrent`, main-actor-by-default, actors, task groups), protocols/generics (`some` vs `any`), API design, performance & ARC, Swift Testing, macros.

**Core takeaways.**
- Model data with value types.
- Stay single-threaded until profiling says otherwise.
- Structured concurrency; Sendable for shared data.
- Swift Testing by default.
- Modern syntax agents often miss.

**When to use.** Any Swift/SwiftUI code.

**When NOT to use.** Non-Swift projects.

## 🇧🇷 Português

**O que faz.** Como escrever Swift moderno: tipos por valor, segurança de concorrência do Swift 6, protocolos e genéricos, design de APIs, desempenho, Swift Testing e macros.

**Principais lições.**
- Modelar dados com tipos por valor.
- Ficar numa thread só até medir.
- Swift Testing por padrão.

**Quando usar.** Código Swift/SwiftUI.

**Quando NÃO usar.** Projetos sem Swift.
