## 🇺🇸 English

**What it does.** Picks the library for a frontend task from Emil's curated list instead of hand-rolling or installing abandoned packages.

**Manual only:** `disable-model-invocation: true` — Claude never picks it on its own; you start it by typing `/pick-ui-library`.

**Core takeaways.**
- Primitives: base-ui · ⌘K: cmdk · toasts: Sonner · drawers: Vaul · OTP: input-otp.
- Motion: motion · numbers: NumberFlow · 3D globe: Cobe · OG images: Satori · code: shiki.
- Charts: recharts / Liveline · DnD: dnd kit · virtualization: Virtuoso.
- State: zustand · classes: clsx / cva · themes: next-themes.
- Catches common mismatches (wrong library for the job).

**When to use.** Before installing a UI dependency.

**When NOT to use.** When the project already standardised on a library.
