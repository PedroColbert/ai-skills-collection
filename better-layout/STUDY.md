## 🇺🇸 English

**What it does.** Sets grouping, alignment, reading order, responsive structure and room for translated text, so a layout survives resizing, translation and RTL mirroring.

**How it works.** `SKILL.md` + `grouping-and-alignment.md` and `spacing-and-adaptivity.md`.

**Core takeaways.**
- Group with space, not lines.
- Align to shared edges; use logical properties for anything that mirrors.
- One primary action per view; hint at hidden content.
- Content bleeds, controls float; inset buttons from edges.
- Plan for growth and clipping (translations are ~30% longer).

**When to use.** Page/section layout, responsive breakpoints, i18n-ready UIs.

**When NOT to use.** Purely visual polish (use `better-ui`).

## 🇧🇷 Português

**O que faz.** Define agrupamento, alinhamento, ordem de leitura e estrutura responsiva, para o layout aguentar redimensionar, traduzir e espelhar.

**Principais lições.**
- Agrupar com espaço, não com linhas.
- Alinhar por bordas comuns.
- Uma ação principal por tela.
- Prever textos maiores (traduções).

**Quando usar.** Layout de páginas, responsividade, interfaces multilíngues.

**Quando NÃO usar.** Só acabamento visual.
