## 🇺🇸 English

**What it does.** Builds several genuinely different versions of a UI piece behind a live visual picker, so you flip through them and promote the one that feels right.

**Manual only:** `disable-model-invocation: true` — Claude never picks it on its own; you start it by typing `/prototype`.

**Core takeaways.**
- Never touches production code during exploration.
- Variants diverge on a named axis (layout, density, personality, motion, interaction).
- Every variant fully works with realistic content.
- The picker is fixed chrome (copied verbatim from `PICKER.md`).
- Cleans up after the choice.

**When to use.** "Not sure what it should look like" — hero ideas, cards, sections.

**When NOT to use.** When the design is already decided.

## 🇧🇷 Português

**O que faz.** Cria várias versões realmente diferentes de uma parte da interface, com um seletor visual para comparar ao vivo e promover a escolhida.

**Só manual:** `disable-model-invocation: true` — o Claude não usa sozinho; você inicia digitando `/prototype`.

**Principais lições.**
- Não mexe no código de produção durante a exploração.
- Cada versão varia num eixo com nome.
- Todas funcionam de verdade.
- Limpa tudo depois da escolha.

**Quando usar.** Quando não sabe como algo deve ficar.

**Quando NÃO usar.** Design já decidido.
